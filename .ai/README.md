# `.ai/` — AI metadata

| Path | Purpose |
|------|---------|
| `specs/` | Active specifications (spec-driven development). Naming: `YYYY-MM-DD-slug.md` |
| `specs/implemented/` | Specs whose implementation is complete |
| `specs/archive/` | Specs that are abandoned, superseded, or obsolete |
| `runs/` | One log per autonomous AI run. Naming: `YYYY-MM-DD-slug.md` |
| `lessons.md` | Index of lessons learned (long-term memory for LLMs) |
| `lessons/` | Detail files for lessons. Naming: `YYYY-MM-DD-slug.md` |

Rules for using these are defined in the root `AGENTS.md`.
